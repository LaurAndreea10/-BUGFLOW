# BUGFLOW Roadmap

## Shipped in v9

- Production center and command palette
- Smart compressed diagram links and read-only presentation mode
- Local comments, snapshot comparison, find/replace, documentation generation
- Graph checks for orphan nodes, dead ends, and cycles
- Keyboard-operable SVG nodes and inline label editing
- Kanban, Sankey, Architecture, Radar, Treemap, and Requirement starters
- Mobile action dock, grid, color-safe palette, and optional LaurAi export branding
- CodeQL, Dependabot, Playwright, Lighthouse, and repository contribution templates

## Candidate v10 integrations

- Optional account-based synchronization
- GitHub Gist publishing after explicit authorization
- Real-time multi-user presence and comments
- Server-rendered PDF and PowerPoint exports

BUGFLOW remains useful without an account and stores personal work locally by default.

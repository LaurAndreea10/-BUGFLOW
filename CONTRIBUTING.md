# Contributing to BUGFLOW

Thank you for helping improve BUGFLOW.

1. Fork the repository and create a focused branch.
2. Keep the app dependency-free unless a change clearly requires otherwise.
3. Preserve keyboard support, visible focus, reduced motion, and the RO/EN interface.
4. Run `node --check app.js` before submitting.
5. Test the affected flow on desktop and mobile.
6. Describe the user-facing change in the pull request.

Please keep pull requests small and avoid including personal or generated browser data.
